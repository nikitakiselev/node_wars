# Node Wars

Стратегия в реальном времени на случайном графе. Узлы копят очки, вы
перетаскиваете отряды по рёбрам и захватываете соседей; побеждает тот, кто
заберёт всю сеть. Соперники — до пяти ботов.

**Играть: https://nikitakiselev.github.io/node_wars/**

## Как играть

Тяните мышью от своего узла к соседнему. Обычное перетаскивание отправляет
половину гарнизона, `Shift` — всё, `Alt` — четверть.

Размер узла — это его потолок очков: крупные растут дольше и стоят драки.
Нейтральные узлы не растут, но обороняются. Атака вровень с обороной узел не
берёт, нужен хотя бы один лишний отряд.

## Разработка

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # правила игры, ИИ и генератор карт
npm run build      # статическая сборка в dist/
```

TypeScript, PixiJS 8 (WebGL), Vite. Игровая логика в `src/core` не зависит ни от
Pixi, ни от DOM и проверяется тестами в Node. Симуляция идёт фиксированным
шагом 30 Гц, рендер интерполирует между шагами.

Почему код устроен именно так — в [docs/design.md](docs/design.md).
